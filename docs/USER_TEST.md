# A 15-minute bookkeeper test

**Status: prepared worksheet. No independent bookkeeper feedback has been collected or claimed.**

This tests whether the bank-matching workflow helps someone make a sound decision. It is not a sales script. Use the supplied fictional data; do not upload a customer's actual financial records.

## Set up

Invite a person who has matched bank payments to invoices. Give them the [live workflow](https://sealwork.vercel.app/new?task=bank&mode=agent). Explain only: “This prototype helps match payments to invoices and checks a worker's report before paying its processing fee.” Ask permission before recording their screen or quoting them. Do not record a private recovery file.

## Tasks and observations

| Task to give the participant | What to observe |
| --- | --- |
| Find the invoices covered by the $900 payment | Can they identify $500 + $400 without coaching? |
| Decide what to do with the $250 payment | Do they preserve Needs review rather than force a match? |
| Explain what they are approving and paying for | Do they distinguish fictional bank dollars from the 0.050 testnet NEAR processing fee? |
| Find the paid result and check its receipt | Can they locate the report, payment and separate verification evidence? |
| Explain how a different browser could read the private report | Do they understand the recovery file and keep it private? |
| Inspect the faulty worker's [refunded receipt](https://sealwork.vercel.app/jobs/sw_cd527cf5498aca5edb472294ca72ade1) | Can they tell why payment was withheld? |

Record completion, time, help required and misunderstandings. Do not silently count coached success as independent success.

## Ask neutral questions

1. What was confusing or missing?
2. Which decisions would you still need to check yourself?
3. How do you handle combined and ambiguous payments today?
4. Where would this fit into that work, if anywhere?
5. What would you need before trusting it with a real client's records?
